# us_party_faction

미국 하원 이념 계파(코커스)의 소속 의원을 106–119대(1999–2026)에 걸쳐 추적하는 사이트.

- 사이트: https://woochangkang.github.io/us_party_faction/
- 출처: Clarke(2020) 복제 자료(106–115대, 집계만 공개), 코커스 공식 회원 페이지 Wayback 보관본(116–119대), Wikipedia 고정 개정판(프리덤코커스 등 2차), Voteview.
- 빌드: `FACTIONS_SRC=<rosters_hist 경로> python3.11 tools/build_site.py` (비공개 원천 폴더에서 읽어 공개분만 `data/`에 쓴다)
- 공개 범위와 정의: `methods.html`
